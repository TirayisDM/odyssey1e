                                Creatures

                                A creature here is a template — a thing you copy from. It has no place in the world, never takes a turn and never appears in a target list. Placing one makes an individual: editing the template afterwards never reaches it, which is why two goblins off one template can die separately.

                                The reference statblocks are shared and read-only — importing takes a copy you own and can edit. The shared goblin stays as it is.

                                A creature file carries names, numbers, scores, skills, prepared spells and the whole kit — but no ids, so it reads into any game. Anything this game has never heard of is skipped and listed rather than refusing the file.

                                No creatures yet. Import one from the reference above, and it will appear here with the full character sheet behind it.
